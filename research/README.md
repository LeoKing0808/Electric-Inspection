# Research Assets

This directory stores non-runtime assets that are useful for model development and demonstrations:

- `nest_detection_demo/`: original bird nest desktop demo and related assets
- `tower_tilt_detection/`: training scripts, datasets, and experiment outputs for tower tilt work
- `runs/`: historical experiment outputs moved from the old project root

Deployable services under `apps/` and `src/` do not depend on this directory at runtime.
