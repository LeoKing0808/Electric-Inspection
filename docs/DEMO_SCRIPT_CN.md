# 企业演示讲解脚本

## 1. 演示目标

本次演示建议围绕三件事展开：

1. 证明模型能力已经封装成标准服务
2. 证明企业系统可以通过标准 API 接入
3. 证明当前项目已经具备继续落地和扩展的基础

## 2. 演示前准备

演示前请确认：

- 服务已经启动
- `GET /healthz` 正常
- token 正常
- 已准备至少一张鸟巢图片 URL
- 已准备至少一张塔身姿态图片 URL
- 日志窗口已经打开

建议同时打开以下窗口：

- 项目介绍文档窗口
- 接口调用窗口
- 返回 JSON 展示窗口
- 服务器日志窗口

## 3. 推荐演示流程

### 第一步：说明项目定位

建议说法：

本项目面向电力巡检图像识别场景，当前已经完成鸟巢检测和塔身姿态检测两项能力，并统一封装成一个可供平台调用的识别服务。

### 第二步：展示健康检查

展示：

```text
GET /healthz
```

建议说法：

这一步展示的是服务层已经启动、模型权重已经加载，不是单独的离线脚本。

### 第三步：展示请求格式

展示：

```json
{
  "task_id": "demo-task-001",
  "image_url": "https://example.com/image.jpg"
}
```

建议说法：

企业侧不需要关心模型路径或推理细节，只需要提供任务编号和图片地址。

### 第四步：展示鸟巢检测结果

重点展示：

- `results.nest_detection.count`
- `results.nest_detection.detections[].bbox`
- `results.nest_detection.detections[].confidence`

建议说法：

当前服务会输出鸟巢数量、目标框和置信度，这类结构化结果可以直接进入企业的告警、复核或工单流程。

### 第五步：展示塔身姿态结果

重点展示：

- `results.tower_tilt_detection.count`
- `results.tower_tilt_detection.summary`
- `results.tower_tilt_detection.detections[].apparent_tilt_deg`
- `results.tower_tilt_detection.detections[].status`

建议说法：

当前输出的是图像平面内的视倾角和状态分级，适合作为巡检辅助识别和自动筛查结果。

### 第六步：展示日志能力

重点展示：

- `service.log`
- `audit.log`

建议说法：

当前服务已经具备基础运维能力，可以追踪请求是否成功、返回了多少目标、是否出现下载或推理异常。

### 第七步：说明接入条件

建议说法：

企业接入时只需要保证能够提供可下载的图片 URL。如果企业当前只有数据库公网 IP，还需要先补一层图片下载服务或对象存储访问层。

### 第八步：说明可扩展性

建议说法：

当前已经完成统一服务框架，后续如果企业需要绝缘子缺陷、异物悬挂、导线异常等任务，可以继续在同一服务框架内扩展，而不需要重新搭建整套接口形态。

## 4. 企业常见问题建议回答

### 问：企业系统如何接入？

建议回答：

企业系统通过标准 HTTP POST 调用即可，传入 `task_id` 和 `image_url`，返回统一 JSON 结果。

### 问：如果企业图片在数据库里怎么办？

建议回答：

当前接口不直接连接数据库。企业需要先提供图片下载 URL，例如文件下载接口、静态图片地址或对象存储地址，再将该 URL 传给识别服务。

### 问：是否支持私有部署？

建议回答：

支持。当前版本已经支持云服务器部署，也支持继续部署到企业内网环境。

### 问：塔身姿态是否是工程真实倾角？

建议回答：

当前输出的是图像平面内视倾角，适合作为辅助判断和自动筛查依据。如果需要工程级校准结果，需要进一步结合固定视角、外参或多视角方案。

### 问：后续还能增加哪些识别任务？

建议回答：

可以继续增加绝缘子缺陷、异物悬挂、导线异常等任务，当前服务框架已经具备扩展基础。

## 5. 演示时避免的表达

建议避免：

- 直接说当前结果等于最终工程结果
- 直接承诺适配所有企业图片源
- 直接承诺当前版本已经满足正式生产要求

建议改为：

- 当前版本已经完成 PoC 和服务化封装
- 当前版本已经具备企业联调基础
- 可根据企业数据源和字段规范继续定制

## 6. 演示结束建议

建议用以下结构收尾：

1. 当前已经完成从模型到服务的最小闭环
2. 当前已经具备企业接口联调条件
3. 下一步可以对齐企业图片源、字段规范和告警规则
4. 后续可以继续扩展更多巡检任务
