# Runtime Model Assets

This directory stores only the runtime assets required by the deployable services.

- `nest_detection/best.pt`: runtime nest detector weights
- `tower_tilt_detection/tower_detector/best.pt`: runtime tower detector weights
- `tower_tilt_detection/thresholds/thresholds.json`: runtime tilt grading thresholds

Training datasets, training checkpoints, demo code, and experiment outputs are kept under `research/`.
